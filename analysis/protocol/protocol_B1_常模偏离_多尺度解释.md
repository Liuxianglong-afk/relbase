## 1. 题目（暂定）

**英文**：How reliable are individual deviations from normative models of functional connectivity in autism? Split-half, between-run and structure–function evidence from ABIDE I and II

**中文**：孤独症个体功能连接常模偏离的信度有多高？来自 ABIDE I 与 II 的分半、跨 run 及结构–功能证据

## 2. 研究问题与理由

近年的研究用常模偏离描述 ASD 的个体异质性，并把"个体之间极端偏离很少重叠"解读为生物学异质性。但个体偏离图本身的测量信度一直没有被检验过：如果偏离图在同一个人的两段数据之间就不一致，那么"重叠低"有一部分可能只是测量噪声。本研究回答：

1. 个体 FC 偏离（z）在同一次扫描的两半之间、在两个独立 run 之间的一致性有多高？在 TC 与 ASD 中是否不同？
2. 极端偏离（|z| > 2）的判定在两段数据之间能重复出现多少？
3. 信度与剔帧后保留时长有什么关系？要达到中等信度大约需要多长的数据？
4. 只看信度达标的分区时，同一个体的结构偏离（皮层厚度）与功能偏离在空间上是否对应？用信度做衰减校正后，这种对应有多强？
5. 只计入可重复的极端偏离后，ASD 的个体异质性（个体之间的重叠）结论是否改变？

## 3. 设计与样本

- 横断面、多站点；ABIDE I 为发现集、ABIDE II 为复现集，共用 DCAN 管线。
- **分半样本**：所有通过共用质控者（FD 0.2 mm、剩余 ≥ 240 s；2026-10-30 为 985 人）。保留帧按时间顺序平均分成前后两半，两半帧数相同，每半至少 120 s。
- **跨 run 样本**：DCAN 中有 ≥ 2 个 run 的合格者（ABIDE I OHSU 约 25 人；ABIDE II OHSU、IP、ONRC 约 125 人）。拼接后的 `desc-filtered` ptseries 按 run 长度切开（`scripts/B00d_run_boundary_check.py` 抽查 12 人，各 run 帧数之和均等于总帧数）；取前两个剔帧后保留 ≥ 60 帧的 run。去噪是在拼接后的数据上统一做的，所以跨 run 的独立性只在采集层面，这一点写入局限。
- **结构**：DCAN fsLR32k 皮层厚度，按 Glasser 360 分区求均值。

## 4. 主要终点（预先写定）

| 编号 | 终点 | 定义 | 报告方式 |
|---|---|---|---|
| **P1** | 分半信度 | 每个分区 FC 强度 z 在前后两半之间的 ICC(2,1)（绝对一致性），分别在 TC 和 ASD 中计算；汇总为 379 个分区 ICC 的中位数与四分位距 | ABIDE I 与 II 分别报告；中位 ICC 的 95% CI 用按被试的 bootstrap（2,000 次，seed 42/7/123/2024）；ASD 与 TC 的差异用置换组标签检验 |
| **P2** | 极端偏离的可重复性 | 前半判为极端（|z| > 2）的被试–分区组合中，后半也判为同方向极端的比例（正向一致率），以及 Cohen κ | 同 P1 |

信度分级（预先写定，冻结前补查并引用来源）：ICC < 0.5 差，0.5–0.75 中等，0.75–0.9 良好，> 0.9 优秀。

## 5. 次要终点

| 编号 | 终点 | 方法 |
|---|---|---|
| S1 | 跨 run 信度 | 同 P1、P2，用 run 1 与 run 2；样本小，按站点汇总报告 |
| S2 | 信度与时长 | 被试层面：两半 z 图的空间相关 ~ 每半保留秒数（GAM）；再用 Spearman–Brown 公式外推达到中位 ICC 0.5、0.75 所需的时长 |
| S3 | 网络层面信度 | CAB-NP 12 个网络加皮层下，网络内与网络间 FC（91 项）的 z 值，计算同 P1 的 ICC；比较分区层面与网络层面的信度 |
| S4 | 结构–功能对应 | 只用 P1 中 ICC ≥ 0.5 的皮层分区：每人计算厚度 z 与 FC 强度 z（全长数据）跨分区的 Spearman ρ；比较 ASD 与 TC（线性模型，协变量：年龄、性别、平均 FD、站点）；用 FC 分区信度对 ρ 做衰减校正（厚度信度暂取 1，作为保守估计）后重新报告 |
| S5 | 校正后的异质性 | ASD 个体之间极端偏离集合的 Jaccard 重叠中位数：分别用（a）全长数据的全部极端偏离，（b）两半都出现的极端偏离；与 TC 比较（置换 10,000 次） |
| S6 | 症状关联（探索性） | 只在 ASD 中，信度达标分区的 z 与 ADOS CSS、SRS 的关联；可用人数不足 100 时只作描述 |

## 6. 常模建模

- 特征：分区 FC 强度（379）、CAB-NP 网络 FC（91）、皮层厚度（360）。
- **每种数据长度单独建模**：全长、前半、后半各自拟合常模，因为数据越短 FC 估计的方差越大，用全长常模去评估半长数据会人为放大 z 值。run 1 与 run 2 **用前半数据的常模评估**：跨 run 子样本只来自 4 个站点（117 人：ABIDEII-OHSU_1 76、OHSU 17、ABIDEII-IP_1 15、ABIDEII-ONRC_2 9），单独拟合不稳定。同一人的两个 run 截到相同保留帧数。剔帧后单个 run 的时长与全样本半长数据的时长并不相同（B11 实测：截齐后 run 中位 222.5 s，全样本半长中位 171 s），因此跨 run 的 z 值存在共同的校准偏差（两个 run 偏差方向相同，对绝对一致性 ICC 的影响较小），结果中报告时长对比，并写入局限。
- 模型：GAMLSS，μ 与 σ 均为 pb(age) + sex；功能特征在 μ 中加平均 FD（全长数据剔帧后保留帧的平均 FD；DCAN 掩膜不提供逐帧 FD，因此各数据长度共用同一个值，写入局限）。分布族在 NO、SHASHo 中按 BIC 选择，在全长 TC 上选一次后，所有数据长度沿用。
- z 值不来自包含本人的模型：TC 用按站点分层的 5 折交叉拟合（seed 42）；ASD 用全部 TC 拟合的模型。
- 站点处理：与课题 A 相同，按站点用本地 TC 重新居中（k ≥ 10 时再按标准差缩放；TC 本人留一）。本地 TC < 10 的站点只进入敏感性分析。
- 校准检验：报告 ASD 结果前，先确认 TC 的 z 均值接近 0、标准差接近 1。

## 7. 敏感性分析

1. FD 阈值改为 0.3 mm。
2. 分半方式改为奇偶帧交替（时间上不独立，作为信度上限的参照）。
3. 图谱改为 Gordon333。
4. 站点处理改为 ComBat-GAM。
5. 差异性排除：以纳入概率的逆（logistic：年龄、性别、FIQ、站点、诊断）加权重算 P1、P2，权重截断于第 1 和第 99 百分位。
6. 只保留男性。

## 8. 已知局限（写进讨论）

- 分半和跨 run 都在同一次扫描内，反映的是短期信度，不是跨天或跨月的重测信度。
- 跨 run 的数据是拼接后统一去噪的，样本也只来自 3 个站点。
- 半长数据的信度会低于全长数据，S2 的外推依赖 Spearman–Brown 假设。
- 皮层厚度没有重测数据，S4 的衰减校正只校正了功能一侧。
- 横断面数据，没有纵向结局。

## 9. 与 B3 的边界

B1 只研究**个体层面**偏离的信度和结构–功能对应；B3 研究**组水平** ASD 与 TC 差异在不同预处理、图谱和站点处理之间的稳健性。B1 不报告组水平的 FC 差异，B3 不做常模和个体偏离。
